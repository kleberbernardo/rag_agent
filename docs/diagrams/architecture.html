LLM
Governance

Prompt management
Four prompts in Langfuse under a production label. Moving the label is a rollback with no deploy. Falls back to templates.py.
Safety policy
Refused before it costs: injection, CPF, CNPJ, API keys. Flagged after it is paid for: a missing citation.
Schema control
Alembic owns the schema. The application checks and refuses, naming alembic upgrade head. It never migrates itself.
Reproducibility
Every run records its model, chunking, RETRIEVAL_K and prompt hash. A score without them compares to nothing.
Cost control
Per-answer estimate, a token ceiling, a search budget per turn, and --max-cost on the suite.
Audit
Question, retrieved passages and answer are one trace. Rotating local logs keep what the platform does not.
Not covered yet: permission-aware retrieval, and scanning the answer for personal data.
